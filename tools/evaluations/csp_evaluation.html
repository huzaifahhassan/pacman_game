    The 3 ingredients of a CSP

    • Variables: the things you must decide (the colour of each region).
    • Domains: the values each variable may take (Red, Blue or Yellow).
    • Constraints: rules about which combinations are allowed (neighbours differ).
    • A solution gives every variable a value without breaking any rule.
    Words you will meet
    Unary constraint
    Involves one variable ("Physics is not on Monday 9:00"). It just removes values from the domain.
    Binary constraint
    Involves two variables ("these regions differ").
    Global / n-ary constraint
    Involves many variables at once (all-different, a row that sums to 15).
    Constraint propagation
    Using the rules to delete impossible values from domains.
    Backtracking
    Assign one variable at a time; when stuck, undo the last choice.
    Local search
    Start with a full (wrong) assignment and repair it.
